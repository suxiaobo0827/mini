# mini-mobile

一个用于测试 GitHub + ChatGPT 协作链路的 Vue 3 移动端模板。

## 技术栈

- Vue 3
- Vite
- Vue Router
- Pinia
- Vant 4
- SCSS

## 本地运行

```bash
npm install
npm run dev
```

默认开发地址：`http://localhost:5173`

## 构建

```bash
npm run build
```
